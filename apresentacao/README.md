# Apresentação Slidev — Projeto 4

Esta pasta contém a apresentação do projeto de folha de pagamento em Slidev.

## Arquivo principal

- `slides.md`

## Pré-requisitos

- Node.js
- npm

## Rodar em modo apresentação

```bash
npm install
npm run dev
```

O Slidev abrirá a apresentação no navegador.

## Gerar versão estática

```bash
npm run build
```

A saída ficará na pasta `dist/`.

## Exportar para PDF

```bash
npm run export
```

Observação: a exportação para PDF usa Playwright/Chromium, por isso pode baixar dependências adicionais na primeira execução.

## Campos a preencher

No primeiro slide, substitua:

```text
Integrantes: preencher nomes e matrículas
```

pelos nomes reais do grupo.
